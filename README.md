# LearnAgenticAI

Study material for learning to build with AI agents, one child repository per source.

For personal use. If you find something useful in here, by all means use it.

| Child | What it is |
|---|---|
| [stanford-cs329z](https://github.com/parker-brown-family/LearnAgenticAI-stanford-cs329z) | Stanford's *CS329Z: Engineering AI Agents*, cut into 61 study clips with notes on why each matters for getting hired and for understanding |

Clone with the children:

```bash
git clone --recurse-submodules https://github.com/parker-brown-family/LearnAgenticAI.git
```
